# Hit & Blow Match

スマホのブラウザで遊ぶ、キーワードマッチング式のオンライン対戦ヒットアンドブローです。

## 起動

```powershell
npm install
npm start
```

PC では `http://localhost:3000` を開きます。

同じWi-Fiのスマホから試す場合は、PC のローカルIPを使って `http://PCのIP:3000` を開きます。

## ルール

- ホストが部屋を作り、同じゲーム・キーワードを選んだゲストが入室します。
- 存在しない部屋には入室できず、使用中のキーワードで部屋を重複作成できません。
- キーワードはサーバー側でハッシュ化し、元の文字列は保持しません。
- 数字は部屋作成時に3桁または4桁を選び、重複なしです。
- 2人がそろった時点で数字設定の30秒カウントダウンが始まります。
- 30秒以内に数字を決定しなければ負けです。両者未決定なら両者とも負けになります。
- 対戦の制限時間は部屋作成時に15秒、30秒、45秒、60秒、無制限から選びます。
- 制限時間を過ぎると無回答として履歴に残り、相手のターンになります。
- 先攻が正解した場合は後攻に最後の回答機会を設け、両者正解ならDrawです。
- 後攻が不正解または時間切れなら先攻が勝ち、後攻だけが正解した場合は後攻が勝ちます。
- 終了後は同じ相手と再戦するか、メインに戻ります。再戦は先攻・後攻を入れ替えます。

## 実況者画面

実況用URLは `/commentator/` です。プレイヤー画面からはリンクしません。
RenderのEnvironmentで `COMMENTATOR_PASSWORD`（4文字以上、推奨12文字以上）と
`COMMENTATOR_SESSION_SECRET`（暗号学的乱数32文字以上）を設定して再デプロイします。
未設定時は閲覧を拒否します。秘密値はGit・チャット・ログに書きません。

ログインはHttpOnly・SameSite=Strictの署名Cookieで365日保持し、再訪時に更新します。
HTTPSではSecure属性が付きます。同じ環境変数ならサーバー再起動後も認証が続き、
パスワードまたは署名キーを変更すると既存の認証は無効になります。
ブラウザのCookie削除・期限切れ・ログアウト後は再入力が必要です。
パスワード自体をブラウザ保存領域へ書き込むことはありません。

全ルームを1秒間隔で取得し、ゲーム・進行状況で絞り込めます。
両者の決定済みの数字、予想履歴、全色が見えるゴーストの両者視点を表示します。
実況APIは毎回認証し、機密情報は通常の対戦WebSocketには追加しません。
実況画面・APIはno-storeで、PWAキャッシュ対象からも除外しています。
全体で5回の誤入力があると15分間ログインを停止します。
既にログイン中のブラウザの閲覧には影響しません。4桁は推測耐性が低いため推奨しません。
